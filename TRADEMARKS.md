# Trademarks

LureRadar is an independent project, not affiliated with, endorsed by, or
sponsored by Rockstar Games, Take-Two Interactive, or any platform holder. All
trademarks belong to their owners.

## How LureRadar refers to third-party names

- Names such as "Grand Theft Auto", "GTA", "Rockstar Games", "Steam", "Epic
  Games", "PlayStation" and "Xbox" appear only **nominatively and
  descriptively**: to describe the launch a campaign pack covers and the brands
  that scammers impersonate.
- No third-party name is used in LureRadar's project name, organisation,
  package name, domain, logo or visual identity.
- LureRadar uses **no third-party assets**: no game art, trailers,
  screenshots, fonts or logos. All visuals are original.
- Brand entries in campaign packs (`packs/*/brands.yaml`) list *names and
  official domains* so that impersonation can be detected. They never include
  logos or design elements.

If you represent a rights holder and have a concern, please open an issue or
contact the maintainers privately via GitHub private vulnerability reporting on the repository.
