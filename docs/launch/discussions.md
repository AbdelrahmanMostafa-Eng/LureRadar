# GitHub Discussions setup

Enable Discussions (Settings → General → Features) and create:

| Category | Format | Purpose |
|---|---|---|
| Announcements | Announcement (maintainers only) | Releases, PC Watch status changes |
| Q&A | Question/Answer | Using the CLI, feeds, extension |
| Lure sightings | Open discussion | Patterns seen in the wild (defanged), before they become packs |
| Campaign packs | Open discussion | Proposals for the next launches |
| Ideas | Open discussion | Features and integrations |
| Show and tell | Open discussion | Dashboards, SIEM rules, home-lab setups |

Pin a welcome post in Announcements linking to the quickstart, the feeds
page, the ethics policy, and the "Report a lure" form.
