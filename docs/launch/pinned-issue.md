# Pinned issue text: "Start here"

**Title:** Start here: report lures, dispute listings, follow PC Watch

**Body:**

- 🔎 Check a link: `uvx lureradar check "<link>"` or the [web checker](https://lureradar.vercel.app/check/) (runs in your browser).
- 🛡️ Block lures: [Pi-hole / AdGuard / uBlock subscriptions](https://lureradar.vercel.app/feeds/).
- 🎣 Saw a lure? [Report it](https://github.com/AbdelrahmanMostafa-Eng/LureRadar/issues/new?template=report-a-lure.yml) (defang the link).
- ⚖️ Wrongly listed? [Dispute it](https://github.com/AbdelrahmanMostafa-Eng/LureRadar/issues/new?template=false-positive-review.yml); we aim to triage within 2 business days.
- 🖥️ Is GTA 6 coming to PC? [PC Watch](https://lureradar.vercel.app/pc-watch/) (official sources only, RSS available).
- 🗺️ What's next: [ROADMAP.md](https://github.com/AbdelrahmanMostafa-Eng/LureRadar/blob/main/ROADMAP.md).
