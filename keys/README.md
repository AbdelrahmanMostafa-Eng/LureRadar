# Feed signing key

`lureradar-feed.pub` (minisign format) verifies the detached `*.minisig`
signatures published next to every feed file.

The key pair is generated by a maintainer, **not** by automation, so the
secret never touches the repository:

```bash
lureradar feed keygen --out keys/lureradar-feed.pub
```

The command writes only the public key and prints the secret once. Store the
secret as the `LURERADAR_SIGNING_KEY` repository secret (Settings → Secrets
and variables → Actions), clear your terminal, commit the public key, and
copy it to `src/lureradar/data/lureradar-feed.pub` so `lureradar feed pull`
verifies by default.

Until that happens, feeds are published with `SHA256SUMS` only and
`feed verify` reports them as unsigned. This is a step on the human checklist.

Rotation: generate a new pair, publish the new public key alongside the old
one for 30 days, then remove the old key.
